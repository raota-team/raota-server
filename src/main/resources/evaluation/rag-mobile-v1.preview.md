## 라벨 검수 규칙

- 관련 매장은 관련성 `1~3`으로 표시합니다. `3`은 직접적으로 적합하고, `2`는 대안으로 적합하며, `1`은 일부 조건만 맞는 후보입니다.
- `DEV`는 프롬프트·검색 정책을 조정할 때 사용하고, `HOLDOUT`은 라벨 검수 후 동결하여 변경 시 데이터셋 버전을 올립니다.
- 개인 취향·거리처럼 현재 서버 계약이 지원하지 않는 조건은 `contractOnly`로 표시하고 기준 점수에서 제외합니다.
- 실제 앱 연결 전까지 결과 표기의 의미는 `모바일 예상 결과`입니다.
